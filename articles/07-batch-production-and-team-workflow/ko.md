# AI 패션 배치 제작: SKU 데이터, 버전 관리, 사람 검수

> 장문 블로그 · 배치 제작

![AI 패션 배치 제작: SKU 데이터, 버전 관리, 사람 검수](./assets/illustration.png)


배치 제작의 어려움은 ‘생성’을 여러 번 누르는 일이 아니다. 색상, 프린트, 핏, 사이즈 표현을 올바른 상품과 계속 연결하는 일이다. 색상 참조를 잘못 놓거나 A 상품의 프롬프트를 B에 복사하면 전체 배치가 재작업 대상이 된다. 상품 데이터, 이미지 권리, 검수 역할, 파일명을 정리한 뒤 적은 SKU로 시험하고 확장한다.

## SKU마다 같은 정보를 기록한다

SKU와 색상별로 코드, 카테고리, 사이즈 범위, 소재, 참조 경로, 유지할 구조, 금지할 추가 요소, 모델 방향, 채널, 검수자를 적는다. 원본 파일은 SKU·각도·버전을 포함하고 생성 결과는 도구·날짜·프롬프트 버전·출력 번호를 붙인다. final-final2 같은 이름은 승인 이력을 알려 주지 않는다. 상품이 바뀌거나 판매 중단되면 관련 이미지와 영상을 빨리 찾아야 한다.

배경·비율·고정 카메라 같은 공통 설정과 색상·네크라인·프린트·소매 길이 같은 SKU별 입력을 분리한다. 일반 배치 프롬프트가 제품 특징을 덮어쓰게 두지 말고 정리되지 않은 사진 폴더를 한꺼번에 올리지 않는다.

## 상태 큐로 책임을 나눈다

상품별 상태를 정보 부족, 생성 대기, 정지 이미지 검수, 영상 검수, 승인, 재작업, 게시, 내림으로 구분한다. 상품 담당자는 사실을 확인하고 제작자는 입력과 버전을 관리한다. 별도 검수자가 독립적으로 판단하고 운영 담당자가 채널과 날짜를 정한다. 색 변화, 패턴 재해석, 길이 오류, 불안정한 움직임 같은 실패 이유를 태그로 남겨 다음에는 입력을 고친다.

## 품질 관리: 공정은 표본, 상품 사실은 SKU별로

카테고리·색상·원단의 표본을 보면 흐름을 평가할 수 있지만, 전체 통과율이 SKU별 확인을 대체하지 않는다. 새 모델이나 템플릿은 첫 배치의 모든 품목을 확인한다. 안정된 뒤에도 색상, 구조, 사이즈 표현은 SKU마다 승인한다. 영상 시작·중간·끝과 동작 전환을 검사한다. 문제는 재작업 큐로 보내고 배치 완료를 승인으로 보지 않는다. 시도 횟수, 사용률, 사람의 작업 분, 납기와 오류 유형을 기록한다.
