# AI 여성복 게시 전 확인할 권리·허가·AI 표시 체크리스트

> 장문 블로그 · 권리와 표시

![AI 여성복 게시 전 확인할 권리·허가·AI 표시 체크리스트](./assets/illustration.png)

## “생성할 수 있음”과 “게시할 수 있음”은 별개다

실제처럼 보이는 여성복 이미지를 만들었다고 상품 사진, 모델 초상, 글꼴, 음악, 장소, 생성 결과의 모든 권리를 얻는 것은 아니다. 이커머스 콘텐츠에는 마켓플레이스 규정, 상품 설명의 정확성, 합성 미디어 표시, 시장별 소비자 기대, 참조 이미지에 포함된 개인정보도 관련된다. 이 글은 운영 체크리스트이며 법률 자문이 아니다. 해외 캠페인 전에는 각 시장 전문가에게 최신 규정을 확인한다.

## 1. 에셋마다 권리 출처를 추적한다

상품 사진, 로고, 프린트, 원단 패턴, 포장 디자인의 권리자와 제3자 AI 서비스에 업로드할 권한을 확인한다. 실물 모델이 등장하면 초상권 동의가 합성 편집, 배경 변경, 애니메이션, 광고, 지역, 기간, 재편집까지 허용하는지 살핀다. 기존 촬영 허가가 모든 AI 변형까지 포함하지 않을 수 있다. 자체 상품 사진, 범위가 명확한 모델 릴리스, 적법하게 허가된 음악·폰트·장소를 사용하고 계약 및 승인 기록을 보관한다.

허가 없는 인터넷 이미지, 경쟁사 사진, 유명인, 직원 얼굴을 가상 착장 실험에 사용하지 않는다. 서비스에서 업로드를 허용해도 출처가 적법하다거나 당사자가 동의했다거나 게시가 정책에 맞는다는 보장은 없다. 업로드 전 불필요한 얼굴, 주소, 주문번호, 내부 SKU를 가리고 서비스의 개인정보·보관·삭제 조건을 읽는다.

## 2. 실제 상품을 정확히 설명한다

색, 소재, 비침, 핏, 사이즈, 장식, 용도는 판매 사실이다. AI가 만든 드레이프, 몸에 붙는 정도, 단추, 주머니와 착용감은 실물과 다를 수 있다. 상품 페이지에는 정확한 치수, 혼용률, 관리 정보를 유지한다. 검증하지 않은 방수성·보정 효과·기능을 암시하지 않는다. 영상이 실제 옷과 다르면 다시 만들거나 콘셉트 이미지라고 분명히 표시하여 실물 촬영으로 오인하게 하지 않는다.

## 3. 시장과 채널별 AI 표시 확인

중국의 AI 생성 합성 콘텐츠 표시 조치는 2025년 9월 1일부터 시행되며 명시·비명시 표시를 다룬다. 생성 콘텐츠를 게시하는 사용자는 이를 선언하고 유통 서비스의 표시 기능을 사용해야 한다고 규정한다. EU AI Act 제50조에는 해당 AI 생성 콘텐츠의 기계 판독 표시와 특정 경우 배포자의 공개 의무가 포함된다. 적용은 콘텐츠, 역할, 시점에 따라 달라진다. TikTok 공식 안내는 정책 범위에 속하는 사실적인 AI 생성 또는 크게 편집된 콘텐츠에 표시를 요구한다. 한 시장의 방식을 전 세계에 그대로 적용하지 말고 게시 직전 해당 지역과 앱의 최신 규정을 확인한다.

## 4. 게시 심사를 실제 프로세스로 만든다

에셋마다 출처와 허가, 서비스와 날짜, 생성 버전, 사람의 편집, 표시 여부, 상품 사실 검토, 담당자, 게시 채널과 시장을 기록한다. 내보내기 전에 화면 표시와 메타데이터가 남는지 확인한다. 편집·압축·자르기가 필요한 신호를 제거할 수도 있다. 광고, 상품 페이지, 일반 소셜 게시물을 각각 검토하고 같은 면책문을 모든 곳에 복사하지 않는다. 실제 인물과 유사한 이미지, 미성년자, 건강 효능 표현은 법무 또는 준법 담당자에게 넘긴다.
